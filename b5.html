Ringkasan CSS Position

static - Posisi default, mengalir normal.

relative - Geser dari posisi asli, tetap menempati ruang.

absolute - Keluar dari alur, posisi relatif ke parent terdekat yang bukan static.

fixed - Tetap di layar, tidak bergerak saat scroll.

sticky - Mengalir normal lalu menempel saat mencapai posisi tertentu.
